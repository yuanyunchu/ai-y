# Claude Code 小白使用教程 v1.0

> 写给第一次用 Claude Code 的同学 —— 从 0 到 1 上手

---

## 一、Claude Code 是什么？

Claude Code 是 Anthropic 官方出的 AI 编程助手，有几种形态：

1. **VSCode 插件**（你现在用的） —— 直接在编辑器里用
2. **桌面 App**（Mac/Windows） —— 独立窗口用
3. **命令行 CLI** —— 终端里用
4. **网页版** —— claude.ai/code

它会帮你：
- 读代码、写代码、改代码
- 理解项目结构
- 运行命令、测试
- 按流程做开发（比如你这个项目的 AI 驱动流程）

---

## 二、最常用的 5 个基础操作

### 1. 让 Claude 读文件

**直接说**：
```
读一下 README.md
```
或者
```
看看 src/main.js 这个文件
```

**技巧**：
- 如果文件短，Claude 会全读
- 如果文件长，它会先读一部分，你可以让它"继续读"

---

### 2. 让 Claude 改代码

**直接说**：
```
把这个函数改成返回字符串
```
或者选中代码后说：
```
优化一下这段代码
```

---

### 3. 让 Claude 写新代码

**直接说**：
```
写一个 Python 函数，输入两个数返回它们的和
```
或者
```
创建一个新的 React 组件叫 UserProfile
```

---

### 4. 让 Claude 运行命令

**直接说**：
```
跑一下测试
```
或者
```
启动开发服务器
```
或者
```
git status
```

---

### 5. Slash 命令（/ 开头的快捷命令）

Claude Code 有一些内置的快捷命令，以 `/` 开头：

| 命令 | 作用 |
|-----|------|
| `/help` | 查看帮助，了解所有可用命令 |
| `/clear` | 清空当前对话 |
| `/config` | 配置 Claude Code（主题、模型等） |
| `/fast` | 切换到快速模式（更快的输出） |
| `/tasks` | 查看任务列表 |
| `/loop` | 循环执行某个任务 |

## 三、你这个项目里的专属命令

在这个项目里，还有一些额外的技能（Skills）：

| 命令 | 作用 | 对应流程阶段 |
|-----|------|-------------|
| `/opsx-explore` | 需求调研 | Explore |

## 五、实用小技巧

### 技巧 1：选中代码再提问

在 VSCode 里选中一段代码，然后直接问 Claude，它会知道你问的是这段选中的代码。

### 技巧 2：让 Claude 一步步来

如果任务比较大，可以说：
```
先别写代码，先告诉我你的思路
```

等你确认思路后再说：
```
好的，开始写吧
```

### 技巧 3：不满意就让它重来

Claude 写的不对，直接说：
```
不对，重新来
```
或者
```
改成 XXX 这样
```

### 技巧 4：让它解释给你听

看不懂的地方就说：
```
解释一下这部分
```
或者
```
用大白话讲
```

## 六、 Claude Code 能做什么 / 不能做什么

### ✅ 能做的
- 读、写、改代码
- 运行终端命令
- 理解项目上下文
- 按流程执行开发任务
- 解释代码、文档
- 写测试、修 bug
- 重构代码

### ❌ 不能做的
- 代替你做决定（最终还是要你拍板）
-  magically 修复所有 bug（有时候需要你给更多信息）
- 理解完全模糊的需求（你得说清楚想做什么）
- 访问需要登录的网站或私有服务（除非配置了）

## 七、常见问题

### Q：Claude 说它不记得之前的对话了？
A：对话太长会被压缩，你可以提醒它："之前我们在做 XXX"

### Q：怎么让 Claude 只改代码不啰嗦？
A：直接说要求，比如："把函数名改成 getUser，不用解释"

### Q：Claude 运行命令失败了？
A：看错误信息，把错误贴给 Claude，让它帮忙解决

### Q：怎么换模型？
A：用 `/config` 命令，或者看 VSCode 的 Claude Code 设置

## 十、VSCode 专属使用技巧

### 技巧 1：选中代码 + @ 引用文件

在 VSCode 中：
- **选中代码**后提问 —— Claude 自动知道你在问这段代码
- **用 @ 引用文件** —— 输入 `@` 然后选文件，比如：`看看 @README.md 和 @package.json`

### 技巧 2：快捷键（看了就能用）

| 快捷键 | 作用 |
|-------|------|
| `Cmd/Ctrl + L` | 选中当前行（连续按会多选） |
| `Cmd/Ctrl + Shift + P` → 输入 "Claude" | 打开 Claude 命令面板 |
| `Cmd/Ctrl + I` | 直接在光标处唤起 Claude（Inline 模式） |

**Inline 模式特别好用**：在代码中间按 `Cmd/Ctrl + I`，直接输入指令，Claude 会在当前位置改代码。

### 技巧 3：善用侧边栏对话

- Claude Code 的对话在侧边栏
- 可以一边看代码一边和 Claude 聊天
- 对话里的代码块可以直接点"插入"或"复制"

### 技巧 4：让 Claude 用你的代码风格

**先让它读你的规范文件**：
```
读一下 project-context/00-global/ 下的所有规范文件，以后按这个风格写代码
```

### 技巧 5：MCP 工具（如果有的话）

Claude Code 支持 MCP（Model Context Protocol）工具，可以连数据库、Jira、GitHub 等。如果项目配置了，直接让 Claude 用就行。

## 十一、模型选择指南：用哪个模型？

### 你的配置（记下来）

| 类型 | 模型 | 用途 |
|-----|------|------|
| **主模型** | doubao-seed-2.0-code | 日常开发、复杂任务 |
| **快速模型** | deepseek-v4-pro | 快速响应、简单任务（/fast 模式自动用这个） |

### Claude 官方模型（参考）

| 模型 | 特点 | 什么时候用 | 速度 |
|-----|------|-----------|------|
| **Claude 3.7 Sonnet** | 均衡型，写代码好 | 日常开发、改代码、写测试 | ⭐⭐⭐ |
| **Claude 3.7 Opus** | 最聪明，会思考 | 复杂问题、架构设计、深度推理 | ⭐⭐ |
| **Claude 3.5 Sonnet** | 快，性价比高 | 快速任务、简单改代码 | ⭐⭐⭐⭐ |
| **Claude 3.5 Haiku** | 最快，便宜 | 简单问题、读文件、解释代码 | ⭐⭐⭐⭐⭐ |

### 其他常用模型

| 模型 | 特点 | 什么时候用 |
|-----|------|-----------|
| **DeepSeek-v4-pro** | 逻辑强，数学好 | 算法、复杂逻辑 |
| **o3 / o3-mini** | 思考深，推理强 | 难题、架构设计 |
| **GPT-4o** | 快，综合好 | 快速实现、样板代码 |
| **Kimi-k2.6** | 上下文超长 | 读整个大项目、很多文件 |
| **Gemini Flash** | 快，便宜 | 简单任务、量产代码 |

### 按任务选模型（参考你项目里的流程）

| 任务 | 推荐模型 |
|-----|---------|
| 需求调研（Explore） | Claude Sonnet 200k / Kimi-k2.6 |
| 架构设计（Propose） | Claude 3.7 thinking / DeepSeek-v4-pro / o3 |
| 核心开发（Apply） | DeepSeek-v4-pro / Claude 3.7 Sonnet |

## 十二、快速模式 / 省电模式

### 快速模式（Fast Mode）

**输入**：
```
/fast
```

**效果**：
- 用更快的模型（通常是 Claude Haiku 或类似的快速模型）
- 输出速度更快
- 适合简单任务：读文件、解释代码、小修改

**什么时候用**：
- 任务很简单
- 你想快速得到答案
- 不在乎答案是否"最完美"

**退出快速模式**：
- 再输一次 `/fast`，或者在设置里切回来

### 模型切换技巧

**临时用某个模型**（这次对话用）：
```
用 Claude 3.7 Opus 来想这个问题
```

**永久切换**：
- 用 `/config` 命令
- 或者在 VSCode 设置里找 Claude Code 的模型设置
